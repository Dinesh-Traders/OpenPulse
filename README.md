# OpenPulse

**Discover open source. Find issues. Track contributions.**

OpenPulse helps developers explore GitHub projects, discover beginner-friendly issues, and track open-source contributions.

## Current Features

- Interactive project and issue search demo
- Filter sample issues by programming language
- Beginner-friendly issue labels
- FastAPI health-check starter endpoint

## Technology

- Frontend: HTML, CSS, JavaScript
- Planned frontend framework: React + TypeScript
- Backend: Python + FastAPI
- Planned database: PostgreSQL
- Integration: GitHub API

## Project Status

🚧 Early development. The current demo uses sample data. GitHub API integration and database features are planned.

## Getting Started

Open `index.html` in a browser to explore the frontend demo.

Backend setup instructions will be documented in `backend/README.md`.
